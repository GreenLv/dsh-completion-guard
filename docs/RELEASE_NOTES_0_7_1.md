# DSH Completion Guard 0.7.1 — Accurate recovery feedback

## English

Upgrade if resumed tasks keep asking for evidence of an already completed test, or send ordinary work through unnecessary clarification and rebinding. Recovery now uses the current results shown by prepare and checkpoint.

Recovery also retains verifiable prohibitions, approval waits and the dependency-free cleanup condition. Short messages prioritize these boundaries and report omitted rows; read-only details preserve long original text. Historical sibling tasks remain history, and unavailable completion evidence is reported as unknown.

Update to `dsh-completion-guard@0.7.1` and restart DSH. Supported hosts remain DSH `0.1.5-rc.2` and `0.1.5-rc.1`. Some combined wait clauses remain unrecognized; this patch does not establish correct model continuation after a commentary answer and compaction. Explicit proof, adopted Goal and release checks retain their own requirements.

See the [English changelog](../CHANGELOG.md#071---2026-09-22) for the changes. Exact-artifact acceptance results belong to the versioned Release attachments; source tests alone are not native acceptance.

## 简体中文

如果恢复任务反复索要已完成测试的证据，或要求普通工作额外澄清、重新绑定，可以升级此补丁。恢复提示现在与 prepare、checkpoint 使用一致的当前结果。

恢复消息保留来源可核验的禁止事项、确认等待和无依赖清理条件。短消息优先展示这些边界并报告折叠数量，过长原文可从只读详情完整取回。历史兄弟任务保持历史身份；完成证据不可用时明确报告未知。

更新至 `dsh-completion-guard@0.7.1` 后请重启 DSH。受支持宿主仍为 DSH `0.1.5-rc.2` 和 `0.1.5-rc.1`。部分复合等待句仍无法识别，本补丁也不证明模型在进度回复回答插问、再经过压缩后一定正确续接。显式 proof、已采用的 Goal 和 release 检查仍分别生效。

具体变化见[中文更新日志](../CHANGELOG.zh-CN.md#0712026-09-22)。精确制品验收结果以对应 Release 附件为准，源码测试不能替代原生验收。
